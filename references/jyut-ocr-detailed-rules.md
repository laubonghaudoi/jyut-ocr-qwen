# Jyut OCR 詳細版面規則

呢份 reference 補充主 skill 嘅版面同文類判斷，適合全文校對、長會議報告、合訂講義、章程、表格、票據、印章同尾頁。PDF 圖像依據、OCR 工具次序、長書分段同完成聲明仍跟主 `SKILL.md`；反覆近形錯字另讀 `common-ocr-traps.md`。

當前 repo 有 `AGENTS.md` 或其他本地指示時，先跟本地規則。

呢度講「對圖」「核圖」「放大」嘅地方，喺本 skill 係流程（phase 3、修書步驟對住裁圖問模型）或者用戶睇 `doubts.md` 時做；agent 喺對話入面唔讀頁圖、唔放大、唔自己裁字（主 `SKILL.md`〈做完之後〉）。

## 書目 metadata 同 heading

- Markdown 開頭若有 `---` metadata block，要原樣保留喺最前面；唔當正文 heading 或頁面雜訊。
- 先界定交付範圍係全掃描本定正文-only。全書識別通常保留只出現一次嘅扉頁、英文題名、版權／CIP、凡例、贊助題記、照片圖說同來源說明；呢啲唔係重複頁面家具。
- 只有 PDF、既有 OCR 或可靠同版書目清楚提供題名、編者、版本、藏本、影印／編審／校對資料時，先補 metadata。現代影印本自己加嘅題頁（叢書名、輯者、版本、據某館藏本影印、編審、校對）照頁面抄入 `---` metadata block，唔好當正文，亦唔好刪走。
- 藏書印、收藏印等後來蓋上去嘅印章唔係書嘅內容，唔使抄，冇抄唔算錯。真係要抄，就用 `〔印：印文〕` 標明係印，放喺印所在嘅位置，唔好當正文句子混入上下文；評分唔計 `〔印：…〕`。
- 全書題名用 `#`；主要議案、報告、呈文、課目或大篇用 `##`；其下章節、`呈文`、`議草`、`批答`、`請議書`、`箚覆` 等按父子關係使用 `###` 以下層級。
- heading 唔只靠短句判斷，要同時睇 PDF 字級、位置、留白、欄位同前後結構。`至……今照修正……` 呢類承接句通常仍係正文。
- 目錄完結後若隨即接正文題名，要結束 list，再另起相應 heading。
- 同頁可能交錯多份短文件；頁頂短句可能係新案，唔一定係上一段續文。反過來，課目突然轉換即使上一頁半句未完，亦要按 PDF 頁序保留，唔好自行補橋接文。
- `箚復爲箚復事……`、`劄復爲箚覆事……` 呢類黐住題名嘅行，可拆成 heading 同下一段正文；唔好順手統一全篇 `箚/劄/剳/札` 字形。

## 段落同跨頁閱讀次序

- 校對後一個語義段落寫成一個 Markdown 段落，唔保留 OCR 原始行寬、直排行、換欄或 page boundary 軟換行。
- 先判斷語法是否完成。上一行結尾係 `第`、`於十`、`未`、`以`、`由`、`可請`、`業經` 等未完語，下一行又接數字、日期、官銜或動詞，多數屬同一段。
- 唔好只因兩行都長就合併；OCR 特別短行可能對應真正新段、短標題、批答、署名或敬語抬頭。
- 奏摺、呈文、請願書入面 `伏候`、`呈請`、`奉`、`欽奉` 後面可能因抬頭另起 `督部堂`、`旨`、`上諭`、`皇上`。要同時睇版面同語氣，唔可以機械黐行或斷段。
- 頁尾接頁首時以閱讀次序為準；欄尾、頁尾、註腳位置同 marker 本身都唔自動代表新段。
- 頁底註腳插入未完正文時，跟 `long-book-workflow.md`：先接完整正文，再將註腳放返所屬完整段落之後。
- PDF 最後正文頁若本身停喺半句，而下一頁係空白或另一篇，忠實保留半句並報告，唔好憑上下文補完。

## 清單、章程同官文

- 目錄、條文、問題、證據、辦法同明顯枚舉可用 tight bullet list；保留原項號，例如 `一`、`二`、`第一條`、`甲一`，唔好轉成現代編號。
- 連續 list items 中間唔加空行；list 同普通段落、heading、來源說明等不同結構之間先留空行。
- 跨 OCR 行或跨頁嘅同一 item 續文縮入該 item；新 item 另起 bullet。縮入行以 `一……`、`甲……`、`乙……` 開頭時，必須對 PDF 判斷係新項定續文。
- 長章程要核對條號連續性。`附說`、解釋同跨頁續文按 PDF 歸入原條，唔好誤開新條。
- OCR 可能漏 item 前嘅 `-`，亦可能將正文中一個字誤造成 bullet marker；若 list 結構令語意突然斷裂，要回到頁圖。
- 來源句、承接句、治本／治標辦法前後嘅說明通常係普通段落，唔因為鄰近清單就一併變成 item。

## 頁面家具

- 刪重複頁眉、頁腳、書脊、頁碼、承印資訊、卷冊標籤、叢書／分類邊欄、OCR 工具標題同空白頁 notice。
- 大型叢書同長報告嘅家具會有大量 OCR 變體；搜尋題名、局名、叢書名同承印片段只係提示，唔可以用全域替換盲刪。
- 課名、堂名、書名或官署名如果落喺正文句內，要保留。疑似家具同正文黐住時，先 render 對位。
- 封面題名可轉成 `#`；封面書脊、館藏章、承印資料、叢書分類同頁碼一般唔入正文，除非目標 repo 明確要求保存。
- 頁底獨立報紙來源、日期、編者題解或檔案來源可能係正文 apparatus；唔好只因位置似頁腳就刪。

## 表格、表單、圖同空白頁

- PDF 明顯係表格就重建表格；直排表格按版面理解欄列，唔照 OCR 行序硬排。
- 冇合併格嘅表寫 Markdown table。有合併格——一格跨幾行（例如一格附註管住幾行）或者跨幾欄（例如一個標題蓋住幾欄）——就寫 HTML `<table>`，用 `rowspan`／`colspan` 表示，因為 Markdown table 表達唔到合併格。唔好為咗塞入 Markdown 而拆格：補空白格等於話啲格係空，將同一段字抄入幾格等於話頁上印咗幾次。
- HTML 表淨係用嚟載合併格，冇合併格就唔好用。寫法要乾淨：`<table>`，表頭行可以用 `<thead>`／`<th>`，每個 `<tr>` 一行，`rowspan`／`colspan` 淨係大過 1 先寫，格內換行用 `<br>`，唔加 style、class 或者其他 tag。印出嚟嘅空白行、空白格照留（`<td></td>` 或者空白 Markdown 格），唔好刪——刪走會令下面每一行錯位。
- HTML 表喺 Markdown 入面要係一個完整嘅 HTML block：`<table>` 由行頭開始，表入面唔好有空行（空行會截斷個 block，後半變返 Markdown，縮入咗嘅 `<td>` 仲會變 code），`</table>` 之後留一個空行先寫正文（唔係嘅話正文會被當成 HTML，唔渲染 Markdown），唔好包喺 code fence 入面。表題可以寫做 `<caption>`，亦可以喺表上面自成一行。
- 金額、人數、地名、罰欵、捐項、投票、列席／缺席清單經常係分欄表格；數字開頭嘅續行未必係新條。
- 表格完成後另算欄數、列數、小計同總數；數值吻合只係結構驗證，唔代替逐字對圖。
- 同一表跨頁而頁頂完全重印相同表頭，可以合成一張 table 並只保留一次表頭；欄名、次序或分組有任何變化就唔可以機械去重。Phase 3 嘅 `stitch_tables.py` 會自動做呢步（見 `long-book-workflow.md`〈跨頁表格〉）；佢冇併、記咗 `table-continuation-undecided` 或者 `table-continuation-blocked` 嘅頁界，入 `doubts.md`，由用戶對住對照圖決定。Final audit 要逐行檢查 unescaped pipe／欄數一致；HTML 表要查每行合埋 `rowspan`／`colspan` 之後闊度一致、`rowspan` 冇超出表尾，亦冇由 `<thead>` 跨入 `<tbody>`（瀏覽器會喺 group 尾截斷）、`<table>` 有收尾，同埋真係有合併格。
- 跨頁 boundary 唔准喺表格行（Markdown 行或者 HTML 表入面嘅行）前後用 `join`：黐合會將兩行表拼成一行，或者將表同段落黐埋。
- table cell 需要保留多行時可以用 `<br>`；拉丁掃描命中 `br` 屬有意格式，但仍要確認無其他雜訊。
- 表單、票據、圖同圖說要轉錄有意義文字；只有 table 更忠實時先做 table。模糊格位唔好默默推斷。
- 印出嚟嘅分類圖、系統圖（用大括號 ︷ ︸ ｛ ｝ 或者連線將名目一層層分類）寫做 Markdown 巢狀清單：一個名目一行「- 名目」，下層縮入兩格，最頂嘅總名喺最外層；名目旁邊括住嘅註緊跟名目寫「名目（註）」（直排括號「︵︶」寫「（）」，摺咗幾欄或者跨過摺縫嘅註接返做一條）；同一層照閱讀次序（直排由右至左）。有名目同時掛喺兩個上層之下（一個括號連住兩枝），樹表達唔到，就寫 Mermaid graph，一條連線一行。圖隔籬嘅正文、摺縫上嘅書名、葉碼唔屬於圖，照正文或者家具處理；圖冇印嘅標點唔好加。邊個名目掛喺邊度睇唔清，照最似嘅寫，另外記低存疑，唔好靜靜揀一個。
- OCR 判空白嘅頁唔好照信：認版式嗰陣睇 survey 報嘅空白頁 candidate 全頁 render（淡字、規則、印章、表格、圖同尾頁小字），睇唔清就唔標空白，照正常頁跑。
- 尾頁有反白、修補塊、遮字或淡墨時，可比較普通圖、反色圖同局部 crop；另一題名或附錄未確認屬本書前，唔好硬併。

## 文類專項

- 速記錄以發言人轉換作強分段訊號，例如 `某號議員謂`、`督部堂代表謂`、`議長謂`。若上一短行只係發言人標籤，下一行係同一人內容，應按版面合成同一段。
- 講義本身可能有 `。`、`。。`、`、` 等舊式標點，必須逐頁保留；唔好因其他無標點書種而批量刪除或正規化。
- 法律、政治、經濟講義可有真實歐文詞源。`[A-Za-z]` 命中係候選檢查，唔係自動雜訊。
- 官文敬語抬頭同直排換欄只係版面信號；最後分段仍要兼顧句法同 PDF 留白。
- 多課合訂講義可用 `##` 表示主要課目，課內章、節、欵逐級下降；唔好因全書合訂就將所有題名壓成同一層。

## 用戶覆核（final pass）

呢一節係用戶（或者 `release` 嘅人手 reviewer）拎住 `final.md` 同 `doubts.md` 對 PDF 覆核時嘅清單，唔係 agent 嘅步驟：agent 跑完 `finish_book.py` 就交付，唔逐頁重看（主 `SKILL.md`〈做完之後〉）。覆核嘅人每頁至少核對：

- 有冇漏段、多收家具、重複頁、錯序、spread／rotation 誤讀或尾頁漏 render；
- 低信心括號同語境不通嘅高信心字；
- heading 層級、真正新段、跨頁 join、list item 邊界、table 同註腳閱讀次序；
- 人名、官職、地名、日期、金額、項號同可重算結構不變量；
- 已校同未校範圍有冇混淆。

刪 marker 同 final audit 由 `finish_book.py` 做，命中寫入 `doubts.md`。完成聲明跟主 skill：唔可以話已逐頁視覺校對；講明缺重頁、外部復原同 `doubts.md` 嘅疑難。
